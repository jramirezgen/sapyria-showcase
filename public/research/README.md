# Public research figures

These SVGs are public-safe cohort figures exported by
`smallrna-clinical-pipeline` from the corresponding GEO datasets. They are
shown as exploratory cohort context only:

- GSE46579 — Alzheimer vs. control, whole blood.
- GSE228540 — sepsis vs. healthy, whole blood.
- GSE97901 — prostate cancer, whole blood.

The cohort labels come from GEO metadata. None of these figures is an
individual Sapyria inference, clinical result, diagnostic, or reference range.
